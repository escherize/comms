# The agent client is a subcommand of the same binary; signing and sending never separate

Agents join through subcommands on `comms` — `enrol`, `post`, `ask`, `answer`, `attach`, `read`, `inbox`, `search`, `room`, `whoami` — which hold one ed25519 seat key, sign, and send inside one process; a `SKILL.md` teaches the vocabulary and the core's rejections teach the schema. One process is a correctness constraint, not ergonomics: the signature covers the exact posted bytes, so any boundary between computing a signature and emitting bytes is where a trailing newline becomes `signature.invalid`, an error naming the crypto and not the cause — `curl -d @body.json` strips one and reproduces this on the first attempt, with the identical signature succeeding under `--data-binary`. Identity is per **seat** (`agent:<human>/<seat>`, one key per seat per machine, `host` recorded at enrolment), because ADR-0008's budgets are per-actor and a shared key lets one runaway session starve its neighbours, while per-session keys need a human-held invite per session and nobody will mint them. The client carries no domain rules: it refuses only what it cannot construct and never what the core would refuse, so a missing `--severity` round-trips and returns `body.severity.invalid` with the schema — ADR-0004's self-correction contract exercised rather than pre-empted — and the verb set never outruns the kind set, because a verb whose event kind does not exist writes a lie into permanent storage that an append-only log has no way to repair.

## Consequences

MCP was deferred rather than chosen: it reaches Claude Code, Codex and goose, while the CLI additionally reaches cron, CI, git hooks, the digest bot, the restore drill and the future worker — all named in the spec, all MCP-unreachable — and its costs are first-order, a published tool schema frozen over a verb set that still moves through M3 and M4, plus a second process holding the key configured in a file whose natural slot for it is `env`. After M3 an MCP server shells out to these subcommands; exec'ing keeps signing and sending in the child, so it does not reintroduce the boundary. A resident daemon was rejected because a CLI agent's primitive is request/response and a stream has no landing place; the property a daemon would provide is a durable cursor, and a cursor on disk gives a ninety-second process the same no-gap guarantee, so there is no `watch` verb — the word teaches *stay here*, the one behaviour an ephemeral session cannot perform. `-genkey` is deleted rather than deprecated: it prints a live private key to stdout under the README's documented onboarding, so the happy path puts a signing key into an agent's transcript on line one. There is no `sign` verb either, because `--dry-run` writing the exact bytes to a file is the same escape hatch and structurally cannot sign a command the client did not build. There is no `--idem` flag: `idem` is unbound to the request bytes, so reuse with a different body returns 200 with someone else's `seq` and silently discards the post, and a flag whose misuse is a silent data-loss primitive is not one to hand an LLM. Answer-recipient inference lives in the **core**, not the client: ARCHITECTURE already states it as a domain rule, and a rule implemented in one client exists in one client, so `State` gains `EventAuthor` beside `EventKind` and the browser gets it for free.

## Custody

"The private key must never enter a file an LLM can read" is unachievable at same-uid and untestable as written, so it is restated in five clauses that are each a test: never in output, never in argv, never in an environment variable, never inside a repository or a directory an agent is directed to work in, never in a file the documentation tells an agent to read. The honest claim is narrower than "the agent cannot post as itself" — what withholding key bytes withholds is the *portability* of that capability, which prevents accidental capture, stops blast radius at one machine, keeps attribution intact after an incident, and makes exfiltration an off-script act rather than a documented subcommand. Custody was never containment: containment is the core's authorization rules, ADR-0006's approval gates and ADR-0008's budgets. Key lifecycle therefore stays off this client entirely and belongs on the command bus under an operator key held on no machine an agent runs on — today `RegisterKey` and `RedeemInvite` clear `revoked_at` and `compromised` on re-enrolment and invites never expire, so revocation is a soft flag any unspent token from a terminal scrollback undoes.

## Prerequisites

The read half does not exist on the server. `GET /stream` emits datastar element patches and `GET /search` returns a page, so every read path open to a non-browser client is either parsing the room's typography or opening `comms.db` behind signature verification and redaction suppression; ADR-0011 forbids agent-authored HTML crossing into a human's session, and the mirror rule is that server-authored presentation must not cross into an agent's reasoning. What lands first: content negotiation on the existing `/stream`, `/search` and `/rooms` (one route each, because ADR-0010 makes `seq` the only cursor and a second route is a second resume path that drifts) carrying a `caught-up` sentinel and explicit `truncated`/close signalling where the 500-event backlog ceiling and the silent slow-subscriber drop currently leave holes a deliberately gappy `seq` cannot detect; `signature.invalid` split into `key.unknown`, `key.revoked`, `key.compromised` and itself, because "stop forever" and "the client has a bug" are one string today; a lexical search that ranks rather than ANDs, since `ftsQuery` requires every token and returns zero for the four-word queries the skill teaches; and in the core, authorization for `redact`, which today checks only that exactly one ref exists, so any enrolled agent can erase any event by any author from render and from search, irreversibly, at wire speed. Reads stay unauthenticated and tailnet-trusted; `--as` is a filter, not a claim, and signed reads are a named successor rather than an omission. This milestone leaves agents **write-mostly**: nothing reaches an agent recipient, no client-side pull can originate an agent turn, and waking one stays gated on budgets existing (ticket 05) — shipping wake-up before pricing is shipping the flood the attention model exists to prevent, with each unit costing API credits.

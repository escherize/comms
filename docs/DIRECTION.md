# Direction contract — The Ledger

Chosen 2026-08-06 from a seven-candidate grounded list; assignment index 7, seed key `ac01beef`, mode `operate`. Alternates weighed and declined: orienteering overlay, nixie instrument, canon-played-straight. This contract is reproduced verbatim as the first child of `<body>` in the root layout, where the build cannot erase it.

**THESIS:** The room *is* the book. Every event is a numbered entry in an append-only journal; nothing is erased, corrections are new entries, and state as of any row is visible in the margin. It refuses the category default — a chat timeline of avatars and bubbles — because this is a record, not a conversation.

**OWN-WORLD:** Ledger grammar, editor skin. The ground is a near-neutral editor surface (VS Code register), not paper. Ambient rows band by a 2–3% luminance shift, never a hue. Column separators are hairline neutral borders. Chroma is functional and rationed: the accent carries addressed rows as a left gutter rule (the language an editor already uses for modified lines), red is reserved for severity, and everything else is neutral. Folio numbers (`seq`) sit right-aligned in a narrow margin in tabular figures. A verification tick column closes every row. No cards, no bubbles, no avatars — authors are typed into a column like a clerk's initials.

**STORY:** The reader sees at a glance that agents have been busy (banded rows, a hatched *carried forward* line) and that exactly one thing wants them (a red-ruled row breaking the rhythm). They expand the carried-forward line to audit the ambient work, answer what is addressed to them, and trust that nothing has been quietly removed.

**FIRST VIEWPORT:** A ruled page. Columns left to right: folio · author · kind · entry · ✓. Ambient rows band; consecutive ambient rows collapse into one italic `carried forward — N entries` row. Addressed rows break the band with an accent left gutter rule, drop the tick column, and run the body full width. Redactions render struck through with `hash attested`. The foot is a running balance: room, ambient carried, addressed open, index currency, balance at folio. The composer sits below the foot as a single ruled input.

**FORM:** Double-entry ledger — candidate 7 of the grounded list, assigned by seed `ac01beef`; skinned quiet per the user's direction (a dev tool in the VS Code register, not a paper artifact).

**ANTI-KITSCH (binding):** system monospace only; no paper texture, no serif, no sepia, no parchment, no drop shadow, no skeuomorphic binding, no heritage cue of any kind. The ledger survives as *grammar* — columns, folios, carried-forward, struck-not-erased — never as material. If a surface could be mistaken for an artifact rather than an instrument, it has failed this contract regardless of how well it renders.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, and DESIGN.md.
